# RIWAAZ by Jiya ✦ Craftsmanship Atelier

> *"Where timeless craft finds a modern soul."*

A luxury web application and storytelling experience for **RIWAAZ by Jiya** — a heritage capsule of handcrafted Indian Punjabi juttis made in 100% genuine leather with artisanal hand embroidery.

---

## ✦ Highlights

- **Cinematic Scroll Animation System**: Framer Motion scroll-driven camera paths, bidirectional transforms, and Ken Burns depth effects.
- **Interactive Capsule Showcase**: 4 handcrafted debut editions with size selector (36–39) and rich studio photography.
- **Two-Step Checkout & Customer Details Form**: Captures customer name, mobile, address, and pin with validation before ordering.
- **Direct WhatsApp Ordering**: Automatically formats full customer order details and sends directly to WhatsApp.
- **Full-Screen Editorial Moments**: High-contrast typography and atelier video film player.
- **Responsive Luxury Design**: Built with React, Tailwind CSS, and Vite.

---

## ✦ Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/khushhal1602-eng/riwaaz-website.git

# Enter project directory
cd riwaaz-website

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:3001` or `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

Generates optimized production bundle in `dist/`.
